The problem

For Imperial's second-year Instruction Set Architecture module, we had to design a CPU in SystemVerilog that correctly runs the RISC-V 32-bit integer instruction set.

What we built

  • A multi-stage pipelined CPU compliant with RV32I.
  • A second version that adds a data cache.
  • An independent C++ test bench that can check the functional correctness of any RV32I CPU, not just ours.
  • GitHub automation that runs checks on every branch, so nothing broken lands on main.

Why it matters

Building the test bench as its own reusable tool meant we could change the pipeline and cache with confidence. It's the same habit I bring to production work: make correctness cheap to check, then move fast.
