The idea

For Imperial's second-year Information Processing project, we built a take on Flappy Bird where you control the bird by physically tilting an FPGA board up and down.

How it works

  • The FPGA runs fixed-point FIR filtering on its accelerometer data to smooth it and remove noise.
  • A local computer reads the filtered data, decides which way the board is tilted, and sends that to Unity over a WebSocket.
  • A Photon server keeps the game state in sync for multiplayer, and the DynamoDB SDK reads and writes the leaderboard.
  • The game sends your jump count back to the FPGA, so the board itself shows how long you've lasted.
